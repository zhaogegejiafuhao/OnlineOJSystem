代码提交说明

                        
    
                            
  • 请提交完整的可执行程序，包含主程序入口：
                                
      
                                    
    • C/C++：必须包含 int main() 函数
      • 
                                    
    • Java：必须包含 public static void main(String[] args) 方法
      • 
                                    
    • Python2/Python3：必须包含 if __name__ == '__main__': 入口
      • 
                                    
    • Go：必须包含 func main() 函数
      • 
                                
    
                            
    • 
                            
  • 程序需要从标准输入读取数据：
                                
      
                                    
    • C/C++：使用 scanf、cin 等
      • 
                                    
    • Java：使用 Scanner、System.in 等
      • 
                                    
    • Python：使用 input()、sys.stdin 等
      • 
                                    
    • Go：使用 fmt.Scan、fmt.Scanf 等
      • 
                                
    
                            
    • 
                            
  • 程序需要将结果输出到标准输出：
                                
      
                                    
    • C/C++：使用 printf、cout 等
      • 
                                    
    • Java：使用 System.out.println 等
      • 
                                    
    • Python：使用 print() 等
      • 
                                    
    • Go：使用 fmt.Println、fmt.Printf 等
      • 
                                
    
                            
    • 
                            
  • 可以参考上方的样例输入输出格式来编写代码
